# 风格提示词方案

给用户选方向时，不要只报风格名；每个方向给一段**可直接使用的提示词**。下面是六个常用起点，按产品改，不要照抄。

## 1. 编辑杂志 / Editorial

- 概念：像一本有主编的杂志，标题有态度，正文可读，图片承担叙事
- 版式：大标题 + 非对称栅格 + 大量留白；首屏允许文字压图
- 字体：高对比衬线标题 + 中性无衬线正文
- 色彩：纸白/墨黑为主，一个强调色
- 动效：标题入场、图片轻微视差
- 适合：品牌页、展览、文化产品、长篇内容
- 风险：产品界面容易显得“好看但不好用”，控件要克制

```text
为【产品】设计【页面】，采用编辑杂志方向：高对比衬线大标题与中性无衬线正文，非对称栅格，纸白底与墨黑文字，单一强调色。首屏以【主图/主标题】为视觉主角，文字可压图但保证可读。区块用编辑式编号和引文建立节奏，动效只用于标题入场和图片视差。必须出现【真实内容】，不要用卡片堆满页面。交付【文件】，在桌面和移动端截图验收。
```

## 2. 瑞士国际主义 / Swiss

- 概念：网格、字号层级、左对齐、信息密度高但不乱
- 版式：12 列网格、严格对齐、大字号数字/标题
- 字体：Grotesk 无衬线，字重对比明显
- 色彩：白/黑/灰 + 一个高饱和信号色
- 动效：几乎没有，只保留状态反馈
- 适合：后台、工具、数据产品、企业官网
- 风险：容易冷、缺乏品牌记忆点，需要一处大胆细节

```text
为【产品】设计【页面】，采用瑞士国际主义方向：12 列网格、严格左对齐、Grotesk 无衬线字体，白/黑/灰为主，用一个高饱和信号色标记主操作。信息密度可以高，但层级必须一眼可读；标题和数字用大字号建立节奏。动效只保留状态反馈，不做装饰动画。必须出现【真实数据/内容】，交付【文件】，桌面与移动端截图验收。
```

## 3. 温暖手作 / Warm Organic

- 概念：有材料感、圆润、像手工做出来的，不像模板
- 版式：柔和容器、错落排布、少量手绘/纸张纹理
- 字体：圆润无衬线或人文衬线，字号偏大
- 色彩：米白、陶土、橄榄绿、暖棕
- 动效：轻微弹性、按压回弹、渐显
- 适合：生活方式、食品、教育、健康、社区
- 风险：容易过度可爱；控件和可读性要保住

```text
为【产品】设计【页面】，采用温暖手作方向：米白纸感背景、陶土与橄榄绿点缀，圆润无衬线标题，柔和容器与错落排布，加入轻微纸张/手绘纹理。主视觉用【真实素材/插画】，动效只做按压回弹和渐显。界面要温暖但不幼稚，正文对比度和触控尺寸必须达标。必须出现【真实内容】，交付【文件】，桌面与移动端截图验收。
```

## 4. 粗野主义 / Brutalist

- 概念：硬边、原始、强对比，像未经修饰的系统界面
- 版式：粗边框、硬阴影、模块直接拼接、少圆角
- 字体：等宽或超粗无衬线，标题极大
- 色彩：黑白 + 荧光色/纯色块
- 动效：瞬时切换、硬切、光标反馈
- 适合：作品集、实验品牌、活动页、创意工具
- 风险：可读性和可用性容易牺牲，表单要单独检查

```text
为【产品】设计【页面】，采用粗野主义方向：黑白高对比、粗边框与硬阴影、少圆角，标题用超粗无衬线或等宽字体，荧光色只做小面积信号。模块直接拼接，不做柔和过渡；动效是即时硬切。必须保证正文可读、表单可用。必须出现【真实内容】，交付【文件】，桌面与移动端截图验收。
```

## 5. 电影感暗色 / Cinematic Dark

- 概念：深色空间、单一光源、焦点明确，像电影海报
- 版式：大留白、中心或偏置焦点、少控件
- 字体：细字重无衬线 + 少量衬线强调
- 色彩：近黑背景、暖金/冷蓝光、低饱和
- 动效：缓慢推近、光晕呼吸、滚动叙事
- 适合：发布页、硬件、游戏、影音、奢侈品
- 风险：小字号对比度、暗色下的状态区分

```text
为【产品】设计【页面】，采用电影感暗色方向：近黑背景、单一暖金或冷蓝光源，细字重无衬线与少量衬线强调，画面像电影海报。首屏只留一个焦点【主视觉】，控件降到最低；动效用缓慢推近、光晕呼吸和一段滚动叙事。暗色下正文和状态必须清晰可辨。必须出现【真实内容】，交付【文件】，桌面与移动端截图验收。
```

## 6. 玩具感 / Playful Toy

- 概念：高饱和、圆润、有反馈，像在玩而不是在填表
- 版式：圆角卡片、弹性布局、夸张图标
- 字体：圆体/几何无衬线，字号大
- 色彩：高饱和多色，但主色只有一个
- 动效：弹跳、拖拽、奖励反馈
- 适合：儿童、学习、游戏、社交、轻量工具
- 风险：信息密度低；专业场景会显得不可信

```text
为【产品】设计【页面】，采用玩具感方向：高饱和主色 + 圆角卡片 + 几何无衬线大字号，图标夸张但语义清楚。交互用弹跳、拖拽和奖励反馈，让主操作像在玩；信息层级仍要清楚。必须出现【真实内容】，不要用 emoji 代替图标。交付【文件】，桌面与移动端截图验收。
```

## 组合与差异检查

- 两个方向至少两项不同：版式、字体、色彩、主视觉、动效
- 不要用同一套骨架换三组颜色
- 组合方向时先写合并后的提示词，再确认一次
- 每个方向都标出：适合什么、风险是什么、推荐哪个
