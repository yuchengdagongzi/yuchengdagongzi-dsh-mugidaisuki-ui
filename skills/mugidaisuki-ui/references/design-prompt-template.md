# 设计提示词模板

复制这份模板，按项目删掉不需要的行；不要把方括号原样交给用户。

```text
你是资深界面设计师。请为【产品/页面】设计【交付物】。

## 产品与用户
- 品类：
- 用户：
- 用户来这个页面最想完成的一件事：
- 使用设备：

## 真实内容
- 必须出现：
- 不能编造：
- 已有品牌资产：

## 视觉方向
- 调性（从产品和受众推出，不要只写“高级/干净”）：
- 版式骨架：
- 字体方向：
- 色彩：
- 图片/图形/材质：
- 动效（最多三处）：

## 约束
- 技术栈：
- 不能改：
- 视口/响应式：
- 可访问性：

## 交付
- 文件/页面：
- 状态：
- 截图证据：

## 验收
- 用户看到什么算“对”：
- 明确不做什么：
```

## 写提示词的检查

- 每一句都能指导一个可见决定：字体、间距、颜色、构图、动效
- 没有“高端、大气、国际化”这类无法验收的词
- 主任务只有一个；其余动作降级
- 写清真实内容和占位内容，不让模型自己编业务数据
- 提示词里的方向与最后交付一致；改方向时先改提示词

## 极简版

时间紧时至少写这五行：

```text
为【谁】做【什么页面】，主任务是【一件事】。
风格从【品类/品牌/参考】来，调性是【三个具体词】。
版式用【骨架】，字体【方向】，色彩【范围】，主视觉【是什么】。
必须出现【真实内容】，不能出现【禁止项】。
交付【文件/页面】，在【视口】验收【标准】。
```
